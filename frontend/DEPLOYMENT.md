# 单机局域网部署

1. 在已有 FastAPI 项目准备模型/C++，或设置 WEBAPP_NO_MODEL=1 并准备 sw2_e30 历史产物。后端仅监听 127.0.0.1:8000；当前仓库未提供该服务。
2. 使用 Node 24，在 frontend/ 执行 npm ci。必要时设置 BACKEND_ORIGIN（不含 /api）。
3. 执行 npm run build，再执行 npm start。重启机器后重新启动后端与 Next 服务；进程不随文件快照保留。
4. 局域网仅开放前端 TCP 3000。浏览器请求始终为同源 /api，FTP 由后端连接控制器。
5. 检查健康徽标；选择 sw2_e30，开启复用历史结果，依次验证识别、点云、标定、生成、预演和下载。FTP 真机测试由项目组值守，确认覆盖风险后进行。

后端不在同一主机时，设置实际 BACKEND_ORIGIN 并重新构建。不要将控制器密码写入配置文件或浏览器持久存储。部署不需要运行时 CDN；首次依赖安装需包注册表访问。
