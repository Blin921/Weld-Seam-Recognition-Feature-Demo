# WELD VISION 前端

Next.js App Router、React、TypeScript strict 与 Three.js。按《NextJS前端需求开发说明书 V1.0》实现五步工作台。运行时不使用 CDN 或远程字体。

## 本机运行（Windows CMD）

先进入本文件所在的 **frontend** 目录，确认 `dir package.json` 能找到文件：

```cmd
cd /d C:\你的项目路径\Weld-Seam-Recognition-Feature-Demo\frontend
npm ci
npm run dev
```

浏览器访问前端 3000 端口。首次安装需要 npm 网络访问；安装完成后构建与运行不依赖外网。

## 后端代理

默认将全部 `/api/*` 同源请求转发到 `http://127.0.0.1:8000/api/*`，没有修改后端。自定义地址在 `frontend/.env.local` 设置：

```dotenv
BACKEND_ORIGIN=http://127.0.0.1:8000
```

修改代理后重新构建及重启。前端默认绑定 `0.0.0.0:3000`，生产启动同样绑定此地址：

```sh
npm run build
npm start
```

当前仓库仅有前端，**不含**文档引用的 `webapp/`、模型、C++ 解算器、`out/weld2tp/sw2_e30`。需由项目组提供既有 FastAPI 服务与历史产物；按该后端实际启动命令设置 `WEBAPP_NO_MODEL=1`，在前端启用“复用历史结果”。没有后端时，真实模式保留空态并提示连接错误；也可从首页主动进入合成数据演示模式。

## 功能

- 13 个 API：健康、帧列表与二进制上传、采集、识别、任务轮询、点云 blob、焊缝、标定保存/查询、程序生成/下载、FTP 下发。
- 全局唯一采集/识别任务，正常时 1.5 秒轮询，失败时保留任务与互斥锁并退避重试（最多间隔 12 秒）；后台页面暂停，切回标签页或网络恢复时立即继续；会话内 20 条任务历史及错误日志。
- 点云零拷贝 TypedArray 解析、内存缓存、预生成语义/实例色、10 mm 网格、统一 `(x,-y,z)` 显示、选择联动。
- 点对表单与矩阵 JSON 标定、残差警告、未标定确认及“禁止上机”提示。
- 全部 ProgramReq 参数、程序预览/复制/下载，按真实生成途经点做 TCP 播放/暂停/拖动/变速，ZYX 姿态与 FINE 停顿。
- FTP 密码仅存在组件内存，其余设置仅在成功下发后本地保存。下发前确认主机、目录及覆盖风险。标定变更会清除旧程序，防止误下发。

## 验证

```sh
npm run typecheck
npm run lint
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

浏览器测试自动启动生产服务，使用**模拟接口**，输出 `test-results/workstation-light.png`、`workstation-dark.png`。若浏览器缓存目录不可写，设置 `PLAYWRIGHT_BROWSERS_PATH` 到可写目录，安装和测试使用同一值。

必须另外完成：真实后端字段核对、sw2_e30 离线闭环、20 万点 30fps 和局域网性能、相机采集、项目组值守下 FTP 真机验收。PDF 未给出 `pairs` 子项的字段定义，当前使用 `{cam:[x,y,z],base:[x,y,z]}`；焊缝按 `id` 和 `trajectory_mm` 读取，需和权威 `webapp/schemas.py` 核对。后端错误 detail 直接展示，不复刻机器人端校验。

## 设计依据与限制

视觉依据用户提供的 6 张页面 PNG（首页、数据采集、AI 识别、标定、程序预演、FTP）。首页使用明确标识的点云示意图；功能页使用真实接口数据，没有将设计图中的示例成功状态、坐标或帧名称当作真实结果。默认浅色预览，保留深色主题。

页面路由：`/` 首页、`/scan` 数据采集、`/recognize` AI 识别、`/calibration` 标定、`/program` 程序预演、`/transfer` FTP 下发，另有 `/seams` 焊缝管理。根布局保留会话工作流组件，客户端页面切换与返回首页不会清空当前帧、运行任务或已生成程序；刷新页面会重新载入后端状态。完整高级参数、日志抽屉、安全确认继续按需求说明书实现。

新增浏览器验证包含：首页功能卡片导航、全部工作流路由、从程序页返回首页再进入后的程序保留，以及浅色、深色和各功能页截图。截图位于 `test-results/`，使用模拟接口，不代表真机联调。

无帧：提供后端数据或上传 PCD。视图 404：先识别或复用历史产物。409：等待另一任务完成。模型未就绪不阻止历史产物模式。坐标超限：先完成标定。FTP 502：检查控制器地址、FTP 服务及网络。

系统只生成与传输文件，绝不触发电机。示教器上的程序选择和启动由现场操作者确认。


## 需求核查后的修复

- 帧列表保留来源徽标（dataset / camera / upload）和“有结果”，中文操作文字至少 14px，坐标、残差及字节数使用等宽字体。
- 1200px 以下将右侧上下文放到左栏“详情与结果”页签，包含焊缝、标定、TCP 与 FTP 结果；1366×768 保留至少 600px 的 3D 视口。
- 步骤显示未就绪 / 进行中 / 就绪状态，程序与下发步骤在未标定时显示警示；空态提供识别或上传入口。
- 轮询超时、网络异常或任务暂不可查询时，不会重新提交任务或解除互斥；后端确认 done/error 才结束跟踪。若后端重启丢失任务，只能报告无法查询，不能凭前端判断该任务已取消。
- 标定残差按帧和 calib_tag 在会话内保留，切换帧不丢警告；标定 tag 改变则丢弃旧残差。刷新页面后，若 GET /calib 不返回残差，前端无法恢复历史残差，需要后端补充权威数据。
- Three.js 渲染器、相机与控制器只初始化一次。配色、点大小、选择和主题局部更新，不重置视角；暂停时切换主题不会重建或隐藏 TCP。轨迹复用 BufferGeometry，卸载时释放资源。
- 验证覆盖任务断线重试、页面隐藏/恢复、残差缓存失效、窄屏详情、渲染器保持、跨页程序保留、安全确认，以及 20 万点约 3.4MB blob 零拷贝解析。浏览器测试使用模拟后端，不能替代真实后端字段核对和设备验收。


## 无后端也能体验的演示模式

启动前端后，在首页点击 **体验演示数据 →**，即可载入两帧程序生成的合成工件（每帧 66,080 点、6 个物体、3 条示例焊缝）。这些不是用户上传的真实扫描，也不是 sw2_e30 历史产物。

1. 识别页：旋转/缩放点云、切换配色、选焊缝；点击“开始识别”体验约 3 秒的模拟任务和日志。
2. 标定页：点击“填入示例点对”，再保存。残差是固定示例值，未执行真实标定求解。
3. 程序页：生成演示程序，播放/暂停/拖动 TCP 轨迹，或下载 `.demo.txt` 示例文本。文件仅包含注释，不是可执行机器人 .LS 程序。
4. 下发页：点击“模拟下发（不连接设备）”，确认后仅显示模拟结果，不建立任何设备连接，发送字节数为 0。

演示由明确的会话标记启用，不会在真实接口失败时自动替换数据。演示接口在浏览器内处理，不请求 `/api/*`，不需要模型、FastAPI、相机或机器人。顶部持续显示“合成示例数据”横幅；点击“退出演示，连接后端”会清空工作流状态并恢复真实接口。演示不修改真实模式保存的 FTP 配置。刷新页面保留演示开关，但会重新初始化示例任务和标定。

浏览器验证包含无后端的完整演示、模拟识别、标定、预演、非执行文档下载、模拟下发及退出模式；截图见 `test-results/demo-recognition.png`、`demo-preview.png`。演示流程验证期间断言没有 `/api/*` 网络请求。

本次演示模式不新增 npm 依赖；已有依赖安装完成的项目更新代码后，重启 `npm run dev` 即可，不必再次执行 `npm ci`。
